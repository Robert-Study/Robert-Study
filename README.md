# Robert Gardner

Physics graduate from the University of Birmingham with interests in scientific computing, numerical simulation and quantitative problem-solving.

My work combines physics, Python and data analysis, with projects spanning stochastic simulation, thin-film optics, signal processing and numerical modelling.

## Featured Projects

### 🔥 Forest Fire Simulation & Analysis
Large-scale stochastic cellular-automaton simulation investigating self-organised criticality, oscillatory population dynamics and fire-size scaling.

- Optimised numerical simulation in Python
- 15+ trillion cell updates in large-scale runs
- Power-law and truncated power-law analysis
- Parameter sweeps and statistical fitting
- Interactive Streamlit visualisation

### 🔬 Rotating-Compensator Ellipsometry
Analysis pipeline developed for a thin-film optics project investigating surface plasmon resonance.

- Harmonic fitting and signal processing
- Instrument calibration
- Fresnel–Airy thin-film modelling
- Extraction of optical parameters
- Numerical optimisation and uncertainty analysis
- Project leader for the wider experimental project

### 🐍 Scientific Python Projects
A collection of assessed computational-physics projects covering quantum systems, Fourier analysis and autonomous rocket landing simulations.
