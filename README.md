## Selected projects

### [Nanophysics Group Project](https://github.com/Robert-Study/Rotating-Compensator-Ellipsometry)

I led an **eight-person experimental project** investigating thin films and surface plasmon resonance. My main work was the rotating-compensator ellipsometry analysis: extracting Ψ and Δ, calibrating the instrument and estimating film properties.

The improved setup and analysis tracked Ψ and Δ approximately **25× more closely than previous-year implementations**. My calibration reduced the remaining tracking error by a **further factor of two**. The silicon-reference thickness was **55 ± 7 nm**, compared with the certified **53.30 nm**.

**71% group mark · 75% individual mark — First Class.**

### [Forest Fire Simulation](https://github.com/Robert-Study/Forest-Fire-Analysis)

A stochastic forest-fire model exploring population oscillations, fire-size distributions and cluster geometry. I extended the coursework with larger simulations, parameter sweeps and event tracking.

The original large-scale result uses **16,000 × 16,000 cells over 8,000 steps: 2.048 trillion cell-time updates**. The model uses periodic boundaries, allowing fires to wrap across the grid.

**74% — First Class.** [Try the interactive simulation](https://forest-fire-analysis.streamlit.app/).

### [Binary Search Tree Optimisation](https://github.com/Robert-Study/Binary-Search-Tree-Optimisation)

An optimisation study of expected rewards across tree keys. For the defined 100-key model, the current solution finds the narrowest contiguous root range—**4–82**—that allows every key to have positive expected reward, then maximises the mean within that range.

The solution uses **40 nonzero root weights**, leaves **zero keys at or below zero**, and gives a mean expected reward of **0.131744** with a minimum-reward floor of **10⁻⁶**. I intend to explore alternative tree constructions to improve the range and reward trade-off further.
