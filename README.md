### [Nanophysics Group Project](https://github.com/Robert-Study/Rotating-Compensator-Ellipsometry)

I led an **eight-person project** investigating thin films and surface plasmon resonance. My main work covered rotating-compensator ellipsometry, Ψ–Δ extraction, instrument calibration and film-property estimation.

My improved setup and analysis tracked Ψ and Δ approximately **25× more closely than previous-year implementations**. A new calibration technique reduced the remaining tracking error by a **further factor of two**, enabling silicon-oxide thickness measurements of **55 ± 7 nm**, compared with the certified **53.30 nm**.

### [Binary Search Tree Optimisation](https://github.com/Robert-Study/Binary-Search-Tree-Optimisation)

An optimisation study examining how root selection affects each key's expected reward in a binary search tree. For a 100-key model with rewards decreasing with search depth, the current solution uses roots **4–82** to give every key a positive expected reward.

The strategy finds the smallest feasible root range, then maximises the mean reward within it. I intend to explore alternative tree constructions to improve this trade-off further.

## Experimental work

### [Atomic Physics Laboratory](https://1drv.ms/b/c/4a8cd531de3d2eb8/IQCydZCXEyXXRYGX54IusWuyAX9yCW92tuoZgfGBUgo1yqQ?e=XzBLd3)

I used Doppler-free laser spectroscopy to resolve the hyperfine structure of rubidium. My analysis aligned oscilloscope recordings, separated the Doppler-broadened and Doppler-free components, and calibrated the frequency axis using a Fabry–Pérot cavity.

Gaussian and Lorentzian fits provided resonance centres and linewidths for estimating magnetic-dipole and electric-quadrupole coupling constants. I also examined how frequency-sweep nonlinearity, alignment and power broadening affected the measurements.

**77% | First Class.**

### [Gibbs–Marangoni Effect: Summer Research Project](https://1drv.ms/b/c/4a8cd531de3d2eb8/IQB8Hye49FXSR7A0i2hvo-G8Ab0BsuLALmtz2v9vtYWGD7U?e=uABOP4)

I investigated how a thin surface film changes the damping of capillary waves, using laser interferometry to measure wave amplitudes at different distances from the source. The experiment compared water, an acetone solution and water covered by a thin olive-oil film.

My analysis corrected for laser-intensity fluctuations, modelled the detector response and used uncertainty-weighted fits to estimate attenuation, connecting the measured wave decay with the investigation of Gibbs–Marangoni damping.

**Main tools:** Python, NumPy, SciPy, Matplotlib, pandas, Streamlit, Git and LaTeX.
